授权 alarmd CLI 读取此环境

授权范围为本部署的运维只读取证，包括策略配置、运行证据和受限的 Redis 数据。管理凭据只在首次配对时输入一次：之后 CLI 自动续期，闲置 30 天或被撤销后才需要重新配对。

输入管理凭据后核对环境。
管理凭据从哪里拿？

就是部署时存进 Secret 的那个值。Secret 与 alarmd 在同一个命名空间，名字是 values 里 cli.adminKeySecret.existingSecret 的值，键名是同一处的 key（不写时为 admin-key）。有该命名空间 Secret 读权限的人可以这样取出：

kubectl -n 命名空间 get secret Secret名 -o jsonpath='{.data.键名}' | base64 -d

取出后只粘贴到本页，不要发进聊天或工单。

会话有效期 1 小时，到期由 CLI 用续期凭据自动换新；续期凭据每用一次换一个。使用 alarmd-cli auth logout --env 环境ID 撤销本机的配对。


 所有已配对的 CLI 都要重新配对；管理凭据轮换后，旧的配对也会自动失效。
