# Review 清单

## 代码

- [ ] 修改范围与需求一致，无无关重构。
- [ ] 新 Java 文件保留项目许可头，包名和格式符合 [代码风格](code-style.md)。
- [ ] 公共 API 有必要的 JavaDoc，可空值已明确标注。
- [ ] 日志使用占位符，无密码、token 或原始敏感数据。
- [ ] 无新增编译器警告，无未说明的反射或 unchecked 操作。
- [ ] 重复逻辑、字面量和依赖按代码规范处理。
- [ ] 数据处理路径的对象使用、集合与 Stream 符合代码规范。

## 验证与兼容

- [ ] `mvn compile`、`mvn test` 通过。
- [ ] 新行为有对应测试；缺陷测试能复现原问题。
- [ ] 涉及恢复链路时完成相应集成测试，并说明未覆盖的场景。
- [ ] 核对 Flink 算子 UID、key、状态描述符和序列化兼容性。
- [ ] 核对 Kafka schema、ES 字段和索引规则的兼容性。
- [ ] 运行配置与实际读取的参数一致，凭据由部署环境提供。

## 文档与提交

- [ ] 用户可见变化已更新文档和 [CHANGELOG](../../CHANGELOG.md)。
- [ ] 配置变更更新 [构建与运行](../overview/source_compile.md)，状态变更更新 [架构说明](../overview/architecture.md)。
- [ ] 未提交密钥、本地配置或构建产物。
- [ ] 提交信息符合 [提交规范](commit-spec.md)。
- [ ] PR 说明问题、修改内容、验证结果和兼容性影响，有关联 issue 时附上链接。
