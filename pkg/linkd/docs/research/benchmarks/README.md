# 性能压测记录

本目录保存 Linkd 在明确配置、平台和负载模型下的性能实验。压测结果只适用于文档记录的边界，
不能直接视为生产 SLA 或跨环境容量承诺。

每份记录至少应包含：

- 测试日期、影响结果的组件版本、资源限制与负载模型；
- 各轮改进或对照变量、持续时间、关键配置及可比性；
- 吞吐、延迟、积压、错误率和必要的资源数据；
- 改进效果、结论依据与尚未验证的边界。

报告按实验问题和结果组织，不记录执行流水账。二进制哈希、本机路径、进程管理、
测试命令与环境清理过程不放入报告；也不把有限窗口结果直接写成长期容量或生产配额。
