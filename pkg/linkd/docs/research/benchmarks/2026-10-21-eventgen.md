# Eventgen 配置驱动改造验证记录

验证日期：2026-10-21。测试环境仅更新 `linkd-eventgen-test`，镜像版本 `0.2.0-test.20261021.1`。控制面、Cleaner、Lifecycle 和 Admin 未更新；Admin 托管模式在本地 HTTP 控制面、真实 ES 与 Kafka 组合验证。eventgen 是测试环境可选工具，默认部署关闭，不作为 Linkd 健康或启动依赖。

## test 环境功能验证

通过现有 Kingeye Admin 操作目录读取 system 租户的真实主机记录及 `test` EventSource。使用真实主机 ID、IP、业务 ID、模型 ID 组成整行绑定，再关联模型行。数据仅保存在本轮私有临时目录和生成 Pod 的临时卷；仓库保留脱敏身份与结果，不保存真实主机数据、完整连接或凭据。

- 第一轮：新增告警速率 0.1/s，发送上限 2/s，3 条生命周期，40 秒运行上限；实际约 29 秒完成。18 次发送全部 Kafka ACK，失败 0、活动 0、队列 0。包含 Standard 警告→严重→降级→恢复、自定义 JSON 触发→关闭、显式时间偏移/发送延迟及 100% 重复投递。
- 下游：16 条唯一事件全部 accepted、enrich succeeded；两条重复投递未重复创建事件。两组 Standard 生命周期各产生 3 个 Alert（先 warning、后 critical、降级后新的 warning），最终均 closed/recovered；自定义 JSON 对应 Alert closed。逐事件确认 fields Processor 的 `environment=test` patch 成功。
- 第二轮：热调整速率后保持原 fingerprint；修改模板时先发旧身份关闭，再切换新轮次。SIGTERM 后补发关闭。最终请求/生效版本均为 3，8 次发送全部确认，其中 2 次为收尾，活动与队列为 0；下游 2 个 Alert 均 closed、enrich succeeded。
- 测试共 26 次发送，不在共享 test 环境做高负载压测。部署保留新版镜像和待命命令，不自动生成流量；配置位于 Pod 临时卷，重启不重跑。

证据：[第一轮生成统计](samples/2026-10-21-eventgen/functional-generator.json)、[第一轮下游结果](samples/2026-10-21-eventgen/test-functional.json)、[热加载及退出统计](samples/2026-10-21-eventgen/reload-generator.json)、[收尾下游结果](samples/2026-10-21-eventgen/test-reload.json)。这里验证的是当前 test 来源的字段丰富，未声称覆盖所有 CMDB 丰富配置、KAC 投影或全部输出插件。

## 本地持续负载

设备 Apple M4 Pro，14 核、48 GiB。Go 生成器运行在 macOS；Apple Container 内 Kafka 3.9.1，2 CPU、3 GiB，单 broker、3 分区、副本 1、明文连接。使用独立临时 topic 和独立消费者校验排空，完成后删除。负载每条告警包含触发和结束两条事件，无远端资源查询；不是完整 Linkd 下游容量测试。测试时其他本地检查也在运行。同配置单独渲染取样（36 字符 run_id、9 位纳秒时间、序号 1 与 5,000,000），触发 JSON 为 384–396 B、恢复 JSON 为 297–309 B，不包含 Kafka key/header 和协议开销；不是长测逐条消息大小分布。

完整记录：[30 分钟负载日志](samples/2026-10-21-eventgen/load.log)。持续负载后增加了 Kafka ACK 按输入记录关联、整数精度保持及可选部署开关；当前代码再次执行真实 Kafka 发布和三档各 10 秒回归，通过且发送失败为 0：[最终 Kafka 回归](samples/2026-10-21-eventgen/final-kafka-smoke.log)。未把前一次长测表述为最终提交逐字节一致的重跑。

短测曾出现新建 Kafka topic 元数据已可见但分区日志尚未就绪，首条消息在三次尝试后失败。集成夹具增加 ListOffsets 就绪等待后回归通过；生产发送策略未增加无限重试或回滚成功批次。

## 本地检查与边界

- Linkd `make check`：格式、普通测试、vet、race、golangci-lint、Console 和 Helm/发行检查通过。
- Eventgen：可复现模板、整行数据关联、类型/转义、多模板、遍历/随机、阶段/分支、暂停继续、速率切换、结构收尾、部分失败、字节预算和退出回归通过。
- ES 7.17.7、MySQL 8.4 真实存储契约通过；控制面→托管进程→Kafka 的真实集成通过。独立生命周期集成使用正式 Cleaner、Lifecycle 与 fields Enrich 代码及内存仓库，不等同 test 部署。
- Admin：格式、lint、类型检查、构建、根路径与子路径页面测试、CLI 五平台发行构建及原生安装/鉴权 smoke、Helm 检查通过。同步最新 develop 后单测首轮 Flinkd 懒加载用例超时；限制为 4 个测试 worker 后全量 1,764 项通过，未修改该业务用例。远端 Admin 和控制面新管理接口尚未部署。

本轮只验证规定范围，不增加自动断言平台或分布式发流量能力。暂停/继续、控制面重启与收尾失败主要由可控时钟、竞态及故障注入测试覆盖，未在共享 test 环境主动破坏 Kafka 或重启控制面。
