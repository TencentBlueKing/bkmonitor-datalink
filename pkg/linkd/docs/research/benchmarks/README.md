# 性能压测记录

本目录保存 Linkd 在明确源码、配置、平台和负载模型下的性能实验。压测结果只适用于文档记录的边界，
不能直接视为生产 SLA 或跨环境容量承诺。

每份记录至少应包含：

- 压测日期、时区、源码提交和被测二进制身份；
- 宿主机与外部组件版本、资源限制和关键配置；
- 流量模型、预热时间、持续时间、停止条件和数据采集方式；
- 吞吐、延迟、积压、失败、后台任务及资源使用数据；
- 已验证结论、未完成实验、容量边界和后续部署建议。
